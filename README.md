# My Niches
My Niches — by Avantex (Usama javed)

A personal library of YouTube niches where each niche is a folder of channels. Paste any YouTube channel or video link, and the app automatically fetches the channel's name, avatar, banner, subscribers, video count, description, and top 3 videos by views (including thumbnails, duration, views, and age). You can write notes on every niche and channel, save channels directly from YouTube with a dedicated Chrome extension, and store your data either in a local file (`data/niches.json`) or in your own free Supabase database. Runs on Node.js 18+ with zero dependencies.
